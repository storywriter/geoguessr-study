# ヨーロッパ周辺の文字形地図帳

- このテーマの原本は `scripts/catalog.py` と `scripts/sources.py`。第一弾のデータ・出力を変更しない。
- 白地図はルートのNatural Earthデータを共用する。地域の図形と学習項目は恒久IDで結ぶ。
- 文字の存在、看板での使用、話者統計を別の根拠として保持する。話者率を看板率へ変換しない。
- 大文字・小文字・結合文字・ラテン文字とキリル文字の混同を確認する。特徴は国を一意に断定するものと表記しない。
- 地域の塗色は概略または行政区の位置案内であり、排他的な言語境界ではない。少数の施設でのみ使う言語は面ではなく点で示す。
- 再生成後はCSV、GeoJSON、地図帳の全項目対応、全字形のフォント収録、PDFの表示を検証する。
