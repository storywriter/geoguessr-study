# 作成方法と読み方

## 対象と収録単位

国連M49の北・西・東・南ヨーロッパ51の国・統計地域、アルメニア、アゼルバイジャン、ジョージア、キプロス、学習上別掲するコソボを対象にした。国連の分類は主権についての判断ではない。ロシアは全域を含める。海外の移民街や欧州外のフランス海外県などは、この巻の対象に含めない。

1行は「国・粗い地域・言語・文字表記」の組。セルビア語のラテン／キリル表記、スイス式ドイツ語などは暗記の目的で分けたため、行数やプロフィール数は言語学上の言語数ではない。カタルーニャ語とバレンシア語、地域別のオック語などは同じプロフィールで注意点を示す。

国・地域の公用語は、使用頻度が低くても収録する。公用語以外は、自治体名・街路名・道路案内・公共施設等の表示が地理的な手掛かりになる地域を選んだ。条約で保護されているだけの言語を、全国の道路標識の主言語とはしていない。全国の主言語が併記地域でも使われることは全国行で表し、全地域に同じ行を重複させない。

この一覧は、全自治体の少数言語指定・あらゆる移民言語・すべての方言の悉皆台帳ではない。文字の違いがほぼなく、公共表示の十分な確認ができない方言や小規模な文化表示は収録しない場合がある。例えばスウェーデンのピーテ・サーミ語は、他のサーミ語と異なる地名表記の公的な採用状況を確認しきれず、この版では独立した地図項目にしていない。

## 一次資料と編集判断

- 国・地域の公的地位と地名表記：UNGEGNに提出された各国地名ガイド、PCGNの地名資料、自治体・政府資料を優先。
- 地域の公共表示：標識に関する行政文書、自治体議事録、欧州評議会の実地調査・実施報告を使用。制度上可能であることと、全道路に設置済みであることを区別。
- 文字：Unicode CLDR 48.2の主・補助文字集合と短い接続表現を保存。CLDRにない言語や地域差は地名ガイドとOmniglotの個別アルファベット資料で補う。後者は二次資料で、人口統計には使わない。
- 特徴字・短語の選択、比較相手、粗い位置への丸めは本地図帳の編集判断。予測モデルで計測した識別精度ではない。

短い語には冠詞・前置詞・接続詞のほか、道・通りを表す語や地名・自称の一部も含む。確かな短語を選べなかった言語は空欄にし、字形だけを示した。すべての字を完全なアルファベットとして列挙したものではない。

## 字形を比べるとき

同じ字は複数の言語にある。`ã`だけならポルトガル語以外も候補、`č š ž`は複数のスラヴ諸語で共通、`ә ө ү`は複数のロシア内の言語が共有する。英語やラテン転写も広域にある。特徴字が見えない短い標識を、除外の証拠にしない。

ルーマニア語の `ș ț`（下のコンマ）と `ş ţ`（セディーユ）、キリルの `ӕ` とラテンの `æ`、キリルの `Ӏ` とラテン `I`・数字 `1` は、字体や画像解像度によって非常によく似る。NFC正規化を用い、文字コードを `unicode_characters.json` に保存した。

CSVの大文字列はUnicodeによる機械的な対応で、実際の道路標識での綴りを保証しない。例えば `ß` はこの処理では `SS` になるが、`ẞ` という大文字もある。アクセント省略、歴史的字体、地域方言、ローマ字転写、撮影年を併せて確認する。

## 数値の扱い

42件の2000年以降の公表値を `data/statistics.csv` に保存した。母語、主要言語、話せる能力、何らかの言語技能、言語集団への所属宣言は別の指標であり、相互換算しない。複数回答のスイスと単一回答の母語統計を足し合わせない。南チロルの言語集団宣言はイタリア国民を対象とし、全住民の母語割合ではない。フィンランドの0.04%はサーミ諸語合計で、個別のサーミ語の割合ではない。

資料のある国・地域とない地域があり、全56地域の比較可能な母語率を揃えたものではない。統計のない項目には架空の値を置かない。モルドバの全国最終値とガガウズ地域の暫定値は明示的に区別し、沿ドニエストルの調査非実施地域には当てはめない。

今回の地図は数値の大小で色を決めないため、全地域に同一指標の数値を補完する必要はない。看板の言語の直接的な資料から掲載範囲を選び、位置の数値として全項目の経緯度・外接矩形・境界を保存した。話者数を看板の使用割合やGeoGuessrの出題確率へ変換していない。

## 地図の範囲・境界

境界の元データは共有のNatural Earth Admin 0 / Admin 1。第一弾のファイルをそのまま利用し、編集していない。国全体、行政区をまとめた概略、国境で切った矩形、代表点の4方式がある。矩形は真の言語境界ではない。少数言語の行政区内にも別言語の住民・表示がある。点は座標を示すだけで一定半径の使用範囲を保証しない。

同一ページの国の基本色の上に地域言語の色を重ねる。別ページの白色は「その言語がない」という意味ではない。アイスランドなど小さい島・飛び地は番号と右のカードで確認する。内陸の無人地も行政区として塗られるが、そこで実際の看板があるという意味ではない。

スイスでは多言語州を単一色へ完全に分割していない。ヴァレー・フリブールのドイツ語側、ベルンのフランス語側、グラウビュンデン内の3言語の細かい境界は、この縮尺では解説で補う。アイルランドのゲールタハトも県全域ではなく飛び地状の地区である。

このテーマで派生する国別形状ではクリミア・セヴァストポリをウクライナへまとめ、ロシア語表示は国境と別の層として扱う。キプロス北部、アブハジア、南オセチア、沿ドニエストルでは法的地位と事実上の表示を区別する。境界・塗色は各当事者の領有権を主張するものではない。戦争と改称の影響を受ける地域は、古いStreet Viewと現在で表示が異なる。

## 検証

国連対象範囲の掲載漏れ、CSVとGeoJSONのID結合、全項目の地図帳への収録、出典・統計ID、図形の有効性、ページ内の参照範囲、フォントの文字収録を検証する。PDFから各言語名と字形を再抽出し、文字列が欠けていないことも確認する。全PDFページはPopplerで画像化し、一覧と必要な拡大で表示を確認した。検証結果と成果物のSHA-256は `data/validation_report.json`。

これは文献に基づく学習資料であり、全道路を現地・Street Viewで一地点ずつ観察した調査ではない。
