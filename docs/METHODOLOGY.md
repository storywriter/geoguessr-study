# 作成方法と限界

## 何を推定したか

対象は、髪を覆い通常は顔が見えるスカーフ等のヒジャブを、住民の普段の生活圏で見かける可能性である。顔を覆うニカブ・ブルカや地域衣装の頭巻きは同一の衣服ではない。見分けに関係するため解説に併記するが、着用数を足し合わせて「ヒジャブ率」にしていない。

世界共通の街頭観察データは取得できなかった。したがって、色・レーティングは編集上の定性推定であり、統計的な確率や、地域内女性の何%以上という厳密なしきい値ではない。高い・やや高いの内部にさらに点数を作ることもしていない。

| 表の判定 | 地図 | 意味 |
|---|---|---|
| 高い | 濃い赤 `#b82338` | 多くの住民女性が着用すると推定する候補。全国調査や服装慣行からの地域への一般化を含む |
| やや高い | 薄い赤 `#f3b6bd` | 一部の住民に日常的に見られると推定する候補。混在、形態差、根拠の弱さも考慮した保守的判定 |
| 低い・判定材料不足 | 白 | CSVには低い行を作らない。未掲載地域で見られない、という意味にはしない |

面積の大きい砂漠や森林にも同じ地域色が付くことがある。これは生活圏を含む地理的な範囲を示すもので、人口密度、女性が街路に出る頻度、撮影地点数を表さない。

## 根拠の使い分け

1. **衣服の直接調査**：インドネシア2022年のヒジャブ通常着用61.9%など。分母はムスリム女性であり、全住民でも全女性でもない。調査の地理的範囲を外挿する際は、各地域の実測率とは表記しない。
2. **頭を覆う服装全般の調査**：Pewの2010年比較など。頭布の種類を限定したヒジャブ調査とは区別する。各国で設問・標本・年齢が異なる調査を平均しない。
3. **宗教人口・地域分布**：国勢調査、Pew 2020年人口推計、USDOSの地域記述。衣服の割合を直接は示さない。数値のない細地域に数字を補完しない。
4. **服装に関する質的資料・制度**：生活上の案内、調査報告、服装に関する聞き取り。法律の存在と実際の遵守率は別である。全国代表の着用率として扱わない。
5. **都市の補足候補**：国・広域の服装資料と地域の宗教分布を参照して位置を選ぶ。首都や大都市の点は着用率を測定した標本地点ではない。都市単位の資料がないものは弱い候補として扱い、市全域を塗らない。

各行の「服装の根拠」が、服装調査の有無と外挿の制限を示す。宗教人口しか取得できなかった国・地域もあり、それらの判定の確かさは低い。資料の出所が信頼できることは、そこから作った地域別の服装推定まで検証済みであることを意味しない。

掲載先の一部には取得制限があり、USDOS原報告の参照リンクのみ残したものがある。その場合は出典一覧に記載し、未読の本文を服装の直接的根拠として扱わない。読めた報告はACCORDの保存版も示す。原報告の宗教人口とPew 2020年推計が違う場合は、異なる資料年・分母・推計法として区別し、都合よく平均しない。

## 宗教人口と服装を混ぜない例

- インドの2019–2020年調査では、ムスリム女性で「家の外で頭を覆う習慣」が89%、衣服名として「ヒジャブ」が8%。南部のヒジャブ回答は23%。語を回答者に定義していない制限もある。89%を「ヒジャブ率」に使わない。
- カシミールのスリナガル地区は2011年にムスリム95.19%。これは女性のヒジャブ率95.19%ではない。本版ではカシミール・ラクシャドウィープも保守的に「やや高い」とした。
- インドネシア2022年の61.9%と、各州の2010年宗教人口比率を機械的に掛け合わせて推定率を作らない。女性比率や着用習慣の地域差を一定とする根拠がないためである。
- 英国タワーハムレッツ39.9%はlocal authorityの住民の宗教人口比率であり、ロンドン全体でもムスリム女性の着用率でもない。
- アフガニスタンや西サハラ等では、顔の覆いや地域衣装との形態差を考慮し、ヒジャブだけについて「高い」と断定しない。

数値の原資料・具体的なページは [SOURCES.md](SOURCES.md) と各CSVの `source_id` に対応する。

## 地域を丸める方法

国の位置を覚えるため、「州名のみ」ではなく東西南北、隣接国、海岸、近くの都市で記載した。離れた人口集積は別行にした。行政区を束ねた範囲、緯度経度で切り出した概略、手描きの概略、面積を持たない都市の点を区別している。

国別・地域別の人口統計は、原統計の区分名のまま保存する。たとえば「マラバール海岸」の範囲とコジコード地区の境界は一致しない。この場合は周辺地区の数値を**関連統計**として列挙し、海岸の合算率を作らない。

インドの地区統計は2011年の区分、インドネシアは33州当時の2010年区分を使用。Natural Earthの州境界にも旧区分が含まれる。新しい州・県の名前に数字をそのまま移植しない。湖や国境の簡略化差は避けられないので、小さな島や町の厳密な行政界を読む用途には使わない。

異なる色の範囲が重なる場合は濃い赤を優先してポリゴンを分割し、同じ国で矛盾する面塗りが重ならないようにする。都市の点と広域の面は別の意味なので、点を囲む架空の居住圏ポリゴンにはしない。

## 国連区分・境界・未掲載地域

UN M49の下位地域を使い、アフリカは北・西・中・東・南部に分ける。国連区分ではイランは南アジア、ロシア全体は東ヨーロッパ。コソボには独立したM49国コードを割り当てず、セルビアの南ヨーロッパ区分を参照し、作業用ISO風コード `XKX` を使用する。

西サハラ、パレスチナ、カシミール、ソマリランドなどの境界・名称の表示は政治的帰属を確定するものではない。地図に使ったNatural Earthの版と処理を保存している。ソマリランドはソマリアの学習範囲に含めた。マヨットは国連の独立した統計地域として扱い、フランス本土に一般化しない。

本版はすべての都市の完全な網羅を保証しない。中国・中央アジア等の、宗教人口が多くても服装や制度の地域差が大きく、現在の街頭傾向を十分に判断できない場所も残る。白色を「住民にムスリムがいない」「ヒジャブは存在しない」と解釈しない。国別の掲載有無は `country_coverage.csv` で確認できる。

## GeoGuessrへの使い方

この資料は `P(服装の手掛かり | 地域)` の定性的な参考であり、`P(地域 | 服装の手掛かり)` ではない。後者は、プレイするマップでその地域が選ばれる事前確率にも依存する。一般マップでの優先順位は、そのマップの収録範囲を確認してから調整する。

撮影年の古いStreet Viewと現在の社会状況も同じではない。紛争や避難、服装の流行・規制は宗教人口より短期間に変わることがある。宗教人口の地域分布が比較的安定している場合でも、服装の傾向まで一定とは仮定しない。
